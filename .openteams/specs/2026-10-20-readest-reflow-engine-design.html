0. 范围

第一期做

  • 把当前 readest/foliate-js 升到跟 Readest 主仓同一提交，替换 assets/foliate/ 里那份旧 vendor
  • 用 esbuild 打一份无 React 的 readest-engine.mjs：重排版 DocumentLoader + getStyles + 脚注接线
  • FoliateHostBridge.setViewSettings 取代薄 setAppearance
  • EPUB / MOBI / AZW / AZW3 / FB2 / FBZ / TXT / MD / HTML 族 / DOCX：滚动默认、可切分页、双栏、正式主题、脚注底栏

  • PDF 并进 foliate（继续 NativePdfScreen + pdf.js）
  • CBZ / CBT / CB7 / CBR（继续 ComicViewer / 兜底岛）
  • TTS、仿生阅读、竖排 / 注音、对话高亮、eink、自定义背景纹理
  • 去掉 -Preader=canvas 回滚

这是「完全迁移 Readest 阅读引擎」的第一子项目。后续独立 spec：PDF/漫画归一、能力层（TTS/仿生/竖排）。一次 spec 装不下整条链。

2. 架构

NativeEpubScreen (Compose chrome)
        │  ThemeKind + ReaderFeatureState
        ▼
FoliateHostBridge
        │  setViewSettings(json) / open / toc / goTo / search
        │  onEvent: relocate | selection | footnote
        ▼
WebView  ← LocalAssetServer  /foliate/*
        │
        ├─ index.html
        ├─ foliate-js view.js / paginator.js / epub.js / mobi.js / fb2.js / footnotes.js
        └─ readest-engine.mjs   ← esbuild: DocumentLoader(reflow) + getStyles + stubs
                │
                ├─ view.open(bookDoc)
                ├─ renderer.setStyles(getStyles(viewSettings, themeCode))
                ├─ renderer.setAttribute('flow', scrolled ? 'scrolled' : 'paginated')
                └─ renderer.setAttribute('max-column-count', n)

现有 engine.mjs 的 open / toc / goTo / search / selectedRange / addHighlight 合同保留；setAppearance 变成对 setViewSettings 的兼容委托（只填 bg/fg/fontSize），正式路径不再手写 html, body CSS。TXT 改走 Readest 的「内存 EPUB」而不是自写 splitTxtChapters 包一层 HTML；MD / HTML / DOCX 仍先由 Kotlin 转 HTML 再当 HTML 书打开（Readest 的 document.ts 不解析 DOCX）。

3. ViewSettings 映射

不搬运 Readest 上百个字段。第一期宿主只写下面这张表，其余用 Readest 默认值（esbuild 入口提供一份 DEFAULT_VIEW_SETTINGS）。

宿主来源ViewSettings 字段规则
ReaderFeatureState.fontScaledefaultFontSizefontSizePx / 1.25（D7）
lineHeightRatiolineHeight原样，clamp 1…2
marginHorizontalPx四边 margin*Px同一值；负值按 0（paginator padding 不能负）
columnsPerPagemaxColumnCountcoerceIn(1, 2)；≥2 即双栏
新字段 scrolled（默认 true）scrolled外观表开关；改完立刻 setAttribute('flow')
ThemeKind 预设themeCode bg/fg + overrideColor=true夜间 isDarkMode=true；护眼/默认 false。不走 Readest 主题名字符串
fontKeydefaultFontsans-serif / serif / monospace 原样；其它 key 第一期忽略，用 serif 链

getStyles 仍是 Readest 那份 1900 行函数，但 eink / 对话高亮 / 用户样式表 / 自定义背景在 DEFAULT 里关掉（isEink=false、dialogueHighlight=false、userStylesheet=''、backgroundTextureId=''），所以这些代码路径第一期不会被打进实际 CSS。

4. 打开与事件

  1. assets.publish(file) 得到 loopback URL（与现网相同）。
  2. JS open(url, format)：EPUB/MOBI/FB2/TXT 走打包后的 DocumentLoader；MD/HTML/DOCX 仍走现有 HTML 书路径。
  3. 打开成功后立刻 setViewSettings，再 goTo(resumeCfi)。
  4. relocate → 进度 CFI（不变）。selection → 现有高亮/词典菜单（不变）。
  5. 章节里的 footnote / noteref 点击：preventDefault 后 onEvent('footnote', { excerpt, href })，Compose 底栏展示正文；无 excerpt 则 goTo(href)。

5. 错误处理

  • bootstrap 20s / open 60s 超时保留。失败文案走现有 openError，不把 JS 堆栈抛到 UI。
  • setViewSettings 抛错只打 AppLog.e，不关书、不回滚主题选择。
  • DocumentLoader 遇到不支持的格式（PDF 误入）返回明确错误 unsupported format in reflow engine，由 FoliateFormats 路由挡住，不该发生。
  • esbuild 产物缺失或 404：bootstrap 失败，走现有「engine unavailable」。
