2. 已选方案与范围

已选择

共享 Chrome + Token

统一系统栏、正文安全区、顶部工具栏与底部进度；格式差异通过 slot 保留。一致性最好，回归范围可控。

仅就地修改

短期改动较少，但 EPUB/PDF 两套实现会继续漂移。未采用。

全部页面重设计

统计、备份、词典等均逐页重画，回归面过大。未采用。

核心页面

书架、EPUB/PDF、全屏目录、阅读设置、笔记/高亮、搜索。其他页面通过 MaterialTheme 继承 Token，不逐页重画。

系统栏动画约束：系统图标不属于 Compose，不能可靠执行图标 Alpha 动画。系统栏与工具栏同步显隐；阅读主题色的状态栏背景/遮罩执行 200ms 淡入淡出，工具栏严格执行 200ms fade + slide。

3. 全屏、系统栏与正文布局

全屏阅读Chrome系统栏正文
关隐藏隐藏背景铺满，文字保留稳定安全区
关显示显示尺寸不变，Chrome 覆盖正文
开隐藏或显示始终隐藏尺寸不变，边缘手势可临时唤出系统栏
  • Activity 只设置一次 WindowCompat.setDecorFitsSystemWindows(window, false)，退出阅读不再切回 true。
  • 状态栏与导航栏透明；窗口背景使用阅读主题色，系统图标按背景亮度切换。
  • 顶部使用 statusBarsIgnoringVisibility + 8dp，底部使用 navigationBarsIgnoringVisibility + 16dp。工具栏显隐不会触发重分页或页面跳动。
  • 阅读横距默认 20dp，可选 12/16/20/24dp。EPUB 传入排版视口，PDF 应用到滚动容器。
  • 退出恢复书架主题和系统栏；不恢复为非边到边。
  • ReaderChromeViewModel 仅用 StateFlow 管理并持久化 UI 偏好，不进入书籍、进度、标注或搜索数据协议。

package com.koodoreader.core.designsystem

object MotionTokens {
    const val FAST = 120
    const val NORMAL = 200
    const val PAGE = 250
    const val SLOW = 300
    const val STAGGER = 30
    const val SHIMMER = 900
    const val HINT = 2000
    const val PRESS_SCALE = 0.98f
    val ALL = listOf(FAST, NORMAL, PAGE, SLOW, SHIMMER, HINT)
}

// :core:ui KoodoMotion.kt
object KoodoMotion {
    val Standard = androidx.compose.animation.core.FastOutSlowInEasing
    val Decelerate = androidx.compose.animation.core.LinearOutSlowInEasing
}

// 工具栏统一规格
val ReaderChromeEnter = fadeIn(tween(MotionTokens.NORMAL, easing = KoodoMotion.Decelerate)) +
    slideInVertically(tween(MotionTokens.NORMAL, easing = KoodoMotion.Decelerate)) { -it }
val ReaderChromeExit = fadeOut(tween(MotionTokens.NORMAL, easing = KoodoMotion.Standard)) +
    slideOutVertically(tween(MotionTokens.NORMAL, easing = KoodoMotion.Standard)) { -it }

// 按压反馈只改变视觉，不消费点击事件，保留原 ripple 和 48dp 触控区域
@Composable
fun Modifier.pressScale(): Modifier = composed {
    var pressed by remember { mutableStateOf(false) }
    val scale by animateFloatAsState(
        targetValue = if (pressed) MotionTokens.PRESS_SCALE else 1f,
        animationSpec = tween(MotionTokens.FAST, easing = KoodoMotion.Standard),
        label = "pressScale",
    )
    this.graphicsLayer { scaleX = scale; scaleY = scale }
        .pointerInput(Unit) {
            awaitEachGesture {
                awaitFirstDown(requireUnconsumed = false)
                pressed = true
                waitForUpOrCancellation()
                pressed = false
            }
        }
}

// 仅 play=true 的首次书架呈现执行；滚动回收时父级已置 false
@Composable
fun Modifier.staggeredEntrance(index: Int, play: Boolean): Modifier = composed {
    if (!play) return@composed this
    val progress = remember(play) { Animatable(0f) }
    LaunchedEffect(play) {
        delay(index.coerceAtMost(12) * MotionTokens.STAGGER.toLong())
        progress.animateTo(1f, tween(MotionTokens.PAGE, easing = KoodoMotion.Decelerate))
    }
    this.graphicsLayer {
        alpha = progress.value
        translationY = (1f - progress.value) * SpaceTokens.md.dp.toPx()
    }
}

5.1 系统栏策略与稳定正文安全区

package com.koodoreader.reader.shell

object ReaderSystemBarPolicy {
    fun shouldHide(fullScreen: Boolean, chromeVisible: Boolean): Boolean =
        fullScreen || !chromeVisible
}

data class ReaderContentInsets(val top: Dp, val bottom: Dp)

@Composable
fun rememberReaderContentInsets(): ReaderContentInsets {
    val density = LocalDensity.current
    val status = WindowInsets.statusBarsIgnoringVisibility.getTop(density).toDp(density)
    val navigation = WindowInsets.navigationBarsIgnoringVisibility.getBottom(density).toDp(density)
    return remember(status, navigation) {
        ReaderContentInsets(
            top = status + SpaceTokens.READER_TOP_EXTRA.dp,
            bottom = navigation + SpaceTokens.READER_BOTTOM_EXTRA.dp,
        )
    }
}

private fun Int.toDp(density: Density): Dp = with(density) { toDp() }

@Composable
fun ReaderSystemBars(
    fullScreen: Boolean,
    chromeVisible: Boolean,
    readerBackground: Color,
    shellBackground: Color,
) {
    val view = LocalView.current
    val window = (view.context as? Activity)?.window ?: return
    val controller = WindowCompat.getInsetsController(window, view)
    val darkIcons = readerBackground.luminance() > 0.5f

    // 每次状态变化只更新系统栏，不执行退出恢复，避免工具栏切换闪色。
    SideEffect {
        window.statusBarColor = AndroidColor.TRANSPARENT
        window.navigationBarColor = AndroidColor.TRANSPARENT
        window.setBackgroundDrawable(ColorDrawable(readerBackground.toArgb()))
        controller.isAppearanceLightStatusBars = darkIcons
        controller.isAppearanceLightNavigationBars = darkIcons
        controller.systemBarsBehavior = WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE
        if (ReaderSystemBarPolicy.shouldHide(fullScreen, chromeVisible)) {
            controller.hide(WindowInsetsCompat.Type.systemBars())
        } else {
            controller.show(WindowInsetsCompat.Type.systemBars())
        }
    }
    DisposableEffect(view, shellBackground) {
        onDispose {
            controller.show(WindowInsetsCompat.Type.systemBars())
            window.setBackgroundDrawable(ColorDrawable(shellBackground.toArgb()))
        }
    }
}

NativeShellActivity 统一设置一次 decorFitsSystemWindows=false；这里不重复切换。退出时由 shell KoodoTheme 恢复图标明暗，ReaderSystemBars 恢复窗口背景与系统栏可见性。

8. 边界、假设与实现顺序

  • 不修改 Book、Chapter、Highlight、Note、Bookmark、ReadingProgress、SearchIndex 或统计数据模型。
  • 不修改 EPUB/PDF 解析、进度映射、标注定位、搜索、同步协议和文件管理逻辑。
  • PDF 原始版式保持原字体与页面比例；17sp/1.6 行高仅用于流式正文和 PDF 重排。
  • 段落间距按已确认规范使用 1.2 × 当前行高；首行缩进 2em 可开关。
  • 列表 stagger 只在首次数据呈现执行，滚动回收不重复。
  • 实现顺序：Token → 系统栏/安全区 → 共享 Chrome → EPUB/PDF 接入 → 书架 → 目录/设置/笔记/搜索 → 自动测试 → 真机验收。
