# Readme Reader 安卓版使用说明

> 适用版本：2.4.4 及之后的 `native` 构建（`-Ptarget=native`）。
>
> 本文档面向**最终用户**，描述当前安卓 APK 在日常使用中可以做什么、怎么做，以及与桌面端相比**尚未提供**的能力。开发者侧的能力清单、ADR、阶段计划见 `docs/android-native-migration.md` 与 `docs/android-engine-capability-inventory.md`。

---

## 1. 简介

Readme Reader 是一款跨平台电子书阅读器。安卓版采用 Kotlin + Jetpack Compose 原生壳 + pdf.js WebView 内核 + Room 本地数据库 的双轨实现：

- **数据层、导入、书库、回收站、备份、统计、词典管理、PDF 阅读、扫描版 PDF 的 OCR 索引检索、漫画屏** — 全部由原生 Kotlin/Compose 实现。
- **EPUB / MOBI / TXT / MD / AZW3 / AZW / FB2 / DOCX / HTML / MHTML / XHTML / CBR 的阅读** — 由应用内嵌的 WebView "兜底岛" 承载，与桌面同源阅读引擎 `kookit-extra`，可获得与桌面端一致的阅读体验。
- **不支持**：云同步（OneDrive / Google Drive / WebDAV / S3 等）、桌面插件系统、自定义 AI 模型在原生侧未接线、部分桌面 P6 功能在原生侧已交付但宿主入口暂缺。

## 2. 安装与首次启动

### 2.1 系统要求

| 项 | 要求 |
|---|---|
| 最低 Android 版本 | Android 7.0 (API 24) |
| 推荐 Android 版本 | Android 10 (API 29) 及以上 |
| 目标 SDK | 34（Android 14） |
| 架构 | `arm64-v8a`、`armeabi-v7a`；CI 拆分两个 ABI，包体更小 |
| 存储 | 约 19 MB（release，arm64 含兜底岛） |

### 2.2 安装

- **Google Play**：搜索 "Readme Reader" 下载（包名 `com.koodoreader.reader`）。
- **侧载（APK）**：从 GitHub Releases 下载 APK，开启「未知来源应用安装」后安装。
- **首次启动**：应用请求以下运行时权限：
  - **通知**（Android 13+，用于听书/OCR 进度通知）
  - **前台服务媒体播放**（用于听书后台播放，屏幕关闭时继续朗读）

> 注：**不会**申请任何存储读取权限，所有本地导入均通过 SAF（系统存储选择器）授予临时读取授权，符合 Android 11+ 范围存储规范。

> **品牌与图标**：应用名与桌面图标为 **Readme Reader**（深海军蓝底 + 展开的书 + 青色文件夹）。自适应图标（Android 8+）由 vector drawable 绘制；传统 launcher PNG 与 Play 商店 512px 图标由脚本生成：
>
> ```
> node scripts/gen-readme-icons.js <品牌logo.png>
> ```
>
> 脚本为纯 Node 实现（无依赖），输出 mdpi~xxxhdpi 五档 `mipmap/ic_launcher.png` 与 `assets/icons/readme-reader-512.png`。

### 2.3 界面概览

启动后默认进入 **书库**（Library）页：

```
┌──────────────────────────┐
│  顶栏：菜单/搜索/导入/视图 │
├────┬─────────────────────┤
│ 侧 │  书籍网格（封面+书名）│
│ 边 │  ……                  │
│ 栏 │  ……                  │
│    │                      │
└────┴─────────────────────┘
│ 底栏：书库/书架/收藏/回收站 │
└──────────────────────────┘
```

- **网格视图**：默认，封面优先。
- **列表视图**：封面+作者+格式+最近阅读时间。
- **视图切换**：顶栏右侧图标。
- **排序**：5 项可排序（名称 / 作者 / 格式 / 最近添加 / 手动）。
- **多选**：长按进入多选模式，可批量移动到收藏/回收站。

## 3. 导入图书

### 3.1 通过菜单导入

1. 在书库页点击 **导入** 按钮（或右上角 `+` 图标）。
2. 选择 **导入单本文件**：弹出 SAF 文件选择器，可一次选择多本。
3. 选择 **导入整个文件夹**：弹出 SAF 文件夹选择器，自动递归扫描至 2 层子目录，最深 1000 个文件。
4. 选择的文件夹授权被记忆，下次启动仍可继续访问；点击 **重新列举**（调用 `listFolder(uri)`）即可再次扫描该目录。

### 3.2 从其他应用打开（"用 Readme Reader 打开"）

支持的接收方式：**文件管理器分享**、**浏览器下载后打开**、**邮件附件**、**分享面板的"发送至 Readme Reader"**。

支持的文件格式（Android 端按 MIME 自动识别）：

| 类别 | 格式 | 导入 | 阅读引擎 |
|---|---|---|---|
| 电子书 | `.epub` | ✅ | 兜底岛 |
| 文档 | `.pdf` | ✅ | **原生 PDF 阅读器** |
| 文档 | `.txt` `.html` `.xhtml` `.xml` `.md` `.mhtml` `.htm` | ✅ | 兜底岛 |
| 文档 | `.fb2` `.docx` | ✅ | 兜底岛 |
| Kindle | `.mobi` `.azw3` `.azw` | ✅ | 兜底岛 |
| 漫画 | `.cbz` `.cbt` `.cb7` | ✅ | **原生漫画屏** |
| 漫画 | `.cbr` | ✅ | 兜底岛 |

> **注意**：直接以 `file://` URI 接收的部分文件管理器受 Android 范围存储限制，应用无法读取时会在屏幕底部弹提示，告知「请改用分享或应用内导入」。

### 3.3 批量去重

导入时会按文件 MD5 计算去重：相同的 MD5 不会重复创建书籍记录，并写入缓存封面与同 key 文件绑定。

## 4. 书库管理

### 4.1 排序与视图

- **网格视图**：封面优先，4 列自适应。
- **列表视图**：左侧封面小图、右侧书名/作者/格式/最近阅读时间。
- **排序项**：名称 / 作者 / 格式 / 最近添加 / 手动（拖拽重排）。
- **拖拽排序**（网格视图长按）：拖动到目标槽位，顺序持久化到本地数据库。

### 4.2 收藏

- 长按书籍 → 弹出操作菜单 → 选择 **添加到收藏**。
- 侧边栏「收藏」可查看所有已收藏书籍。

### 4.3 书架分组

书架（Shelf）是书籍的逻辑分组：

1. 长按书籍 → **移动到书架** → 选择目标书架。
2. 侧边栏顶部 + 号 → **新建书架**。

> **当前限制**：原生壳侧「把书拖入书架」的悬浮 ghost 效果仍打磨中；目前推荐使用菜单操作。

### 4.4 回收站

- 长按书籍 → **移到回收站**：书籍从主列表消失、笔记/书签/进度保留。
- 侧边栏「回收站」→ 选择书籍 → **恢复** 或 **彻底删除**。
- **彻底删除** 会同时清理该书的本地文件、封面、笔记、书签，且不可恢复。

## 5. 阅读

### 5.1 通用手势

- **左右滑动 / 点击左右 1/4 区** → 翻页。
- **点击中央** → 唤出工具栏与菜单。
- **长按** → 选择文本（划词）。
- **捏合手势** → 缩放（PDF、漫画）。

### 5.2 PDF 阅读（**原生实现**）

PDF 阅读器是当前安卓版**真正原生**的阅读器，使用 pdf.js 在应用内嵌的 WebView 中渲染，由原生 Kotlin/Compose 承载工具栏、导航、大纲与分享。

#### 5.2.1 工具栏

PDF 阅读器顶栏按钮从左至右：

| 按钮 | 功能 |
|---|---|
| 返回 | 退出阅读 |
| 大纲 | 打开/关闭目录（书签结构） |
| 搜索 | 全文档文本搜索（区分大小写） |
| OCR | 打开 OCR 索引对话框（扫描版 PDF 适用） |
| 缩放 −/+ | 缩小/放大渲染宽度 |
| 分享 | 导出当前页为 PNG 并分享到系统分享面板 |

#### 5.2.2 导航

- **左右 1/4 点击区**：上一页 / 下一页。
- **底部 ‹ / › 按钮**：单页前后翻。
- **缩放**：基于视口宽度，按比例渲染。

#### 5.2.3 大纲

- 显示 PDF 自带的书签目录（Outline）。
- 大纲未解析的条目会保留并以灰色显示，避免在解析失败时丢失信息。

#### 5.2.4 搜索

- 打开搜索框后，输入关键字。
- 引擎按页扫描文本层，命中项展示所在页码 + 上下文片段 + 矩形坐标。
- 点击命中项跳转；可在结果列表中循环跳转。
- **限制**：搜索作用于 PDF 自带的文本层；扫描版 PDF（无文本层）请用 **OCR** 入口。

#### 5.2.5 加密 PDF

- 首次打开加密 PDF 时弹出密码输入框。
- 密码错误时显示 "Wrong password"，可重新输入。
- 同一会话内已解锁的文件不重复询问。

#### 5.2.6 分享当前页

- 工具栏 → 分享 → 当前页被栅格化为 PNG，存放在应用缓存（`cacheDir/pdf-shots/`）。
- 系统分享面板出现，可分享至任意支持图片的应用（聊天、邮件、笔记等）。

#### 5.2.7 当前边界

- **批注/高亮暂不可用**：原生 PDF 渲染采用栅格宿主，文本层无法直接选择；要支持批注需更换宿主设计，属后续阶段范围。
- **多页连续滚动 / 双页 / 阅读位置记忆**：尚未接入；阅读进度不会自动持久化。

### 5.3 漫画屏（CBZ / CBT / CB7 — **原生实现**）

以 VIEW/SEND 方式打开，或从书库选择 CBZ / CBT / CB7 漫画文件时，进入原生漫画屏：

- 支持 **zip** / **tar** / **7z** 三种容器。
- 自动按自然排序识别页码。
- 懒加载：仅渲染当前页 + 后 3 页；卸载 -4 页之前的位图，控制内存。
- 手势：左右滑动翻页、捏合缩放、双击放大/还原。

> **CBR** 暂不支持原生阅读（无可靠的纯 JVM RAR5 解压器），将由兜底岛接管。

### 5.4 兜底岛阅读（EPUB / MOBI / TXT / MD / AZW3 / FB2 / DOCX / HTML / MHTML）

这些格式的阅读由应用内嵌的 WebView 承载，加载与桌面同源的 `kookit-extra` 阅读引擎：

- 完整的 **翻页、滚动、分栏** 体验。
- **目录、进度、书签、笔记、高亮、脚注、内链** 全功能。
- **主题、字体、行距、段距、边距、背景色、文字色、亮度** 等阅读设置。
- **听书（TTS）** ：从工具栏"听书"图标进入。
- **划词菜单**：长按文本后弹出原生菜单，包含 复制 / 高亮 / 笔记 / 分享 / 搜索（用所选文本调用 Google 搜索或系统词典）。
- **图片查看器**：点击书内图片全屏查看，可缩放。
- **内链跳转**：点击目录、章节、页码、注释标记跳转。
- **字体导入**：通过 WebView 文件选择器导入 `.ttf` / `.otf`，存于应用内 IndexedDB，无需任何原生权限。
- **OCR（兜底岛侧）**：内置 Paddle/Tesseract 引擎，按需加载。

> **桌面独占能力在兜底岛内不可用**：
> - 云同步插件
> - `better-sqlite3` 高级查询
> - 原生 OCR 桌面引擎
> - 桌面插件注册表

## 6. 听书（TTS）

### 6.1 进入方式

- 兜底岛阅读器内，工具栏 → **听书** 图标。
- 系统通知（前台服务）会显示当前朗读章节与播放控件。

### 6.2 引擎

- 使用 Android 系统 `TextToSpeech` API。
- 已通过 `<queries>` 声明 `android.intent.action.TTS_SERVICE`，Android 11+ 也能正确发现所有已安装的 TTS 引擎（如 Google TTS、讯飞语记、有道云语音等）。

### 6.3 控制项

- 播放 / 暂停 / 上一句 / 下一句 / 停止。
- **语速**（speed）、**音调**（pitch）、**音量**（volume）。
- 屏幕关闭后继续播放（前台服务 `mediaPlayback`）。

### 6.4 锁屏与媒体按键

- 锁屏显示媒体控制卡片（来自系统的 MediaSession）。
- 耳机上的播放/暂停/上一首/下一首 物理按键可控制播放。

### 6.5 已知限制

- 当前 TTS 启动 UI 仍在接入过程中：**已实现** manifest/服务/权限/通知，**未实现** "在阅读器中弹出控制条" 这一宿主入口。可临时通过系统通知卡进行控制。
- 通知文案的部分按钮（Stop/Play/Pause/Resume 等）的桌面 zh-CN 翻译未覆盖，暂显示英文。

## 7. 词典（MDX/MDD）

### 7.1 进入方式

书库页 → 侧边栏菜单 → **词典**。

### 7.2 管理功能

- **启用 / 停用** 单本词典。
- **设为默认** ：划词查询时优先使用。
- **上移 / 下移** ：调整查询优先级。
- **删除** ：移除词典文件与索引。
- **Bundled / Imported** 标签：标识词典来源。

### 7.3 导入

- 词典页 → **导入** → SAF 多选文件。
- 支持 `.mdx` 与同名 `.mdd`（音频/图片资源）自动配套导入。
- 导入后的词典目录布局与桌面版一致（`dict/<id>.<ext>` + `dict-index.json`），可直接将桌面词典目录搬到安卓的相同位置。
- 文件名净化：分隔符与路径穿越字符会被替换为 `_`，全符号名会回退到 `dictionary`。

### 7.4 划词查询

- 在兜底岛阅读器内长按单词 → 原生菜单 → **搜索**，所选文本自动传入桌面词典管线。
- 命中后弹出词典查询面板。

### 7.5 已知限制

- **云端词典下载区** 暂未挂载：当前只能从本地文件导入。要启用云端，需要额外的 HTTP 下载模块接入。

## 8. 阅读统计

### 8.1 进入方式

书库页 → 侧边栏菜单 → **Reading Stats**。

### 8.2 指标

- **Total reading time** ：累计阅读时长。
- **Books read** ：已读完的书籍数。
- **Word count** ：累计阅读字数。
- **Daily average** ：日均阅读时长。
- **Reading Activity** ：近 N 天每日阅读量柱状图。
- **Reading streak (days)** ：连续阅读天数。
- **Last 30 Days** ：最近 30 天的阅读折线图。
- **Reading progress** ：单本书的进度分布（按书）。

### 8.3 已知限制

- 原生阅读器（PDF / 漫画屏）目前**不持久化阅读进度**，因此原生侧的统计数字尚未累加（仍显示 0）；桌面导出的统计 DB 可在恢复备份后被读取。

## 9. OCR（扫描版 PDF）

### 9.1 进入方式

PDF 阅读器 → 工具栏 → **OCR** 图标 → 弹出 OCR 索引对话框。

### 9.2 索引流程

1. 打开 PDF 后点击 **OCR**。
2. 选择 **Index this page**（只索引当前页）或 **Index all pages**（索引全书）。
3. 弹窗显示：
   - 模型加载状态（"Recognizing"）。
   - 已索引页码数。
   - 逐页进度条（确定进度）。
   - **OCR model unavailable** ：当设备无 Google Play 服务或离线时显示。
   - **Cancel** ：中断索引循环。
   - **Clear OCR index** ：清除当前书的 OCR 索引。

### 9.3 检索

- OCR 索引对话框内嵌搜索框。
- 输入关键字 → 列表展示命中页码 + 上下文片段（评分 = 0.75·token 覆盖 + 0.25·整串命中）。
- 点击命中项 → 跳转到对应页。

### 9.4 模型下载

- Latin 与 Chinese 脚本在**安装期**通过 `meta-data` 触发 Google Play 服务预取。
- 日语 / 韩语 / 天城文（梵文衍生）在**首次使用**时按需取模。
- **离线 / 无 GMS 设备不可用**，属该路线固有代价。

### 9.5 已知限制

- **不自动后台索引**：桌面端是边读边自动 OCR；安卓端改为显式点击触发，避免耗电、发热以及 OCR 文本落盘的隐私问题。
- 首次检索前需要手动索引（按需索引 900 页扫描版约数十秒到分钟级，进度条可见且可取消）。
- OCR 脚本语言跟随系统 UI 语言切换；如需识别其他语言书籍，请先切换系统语言。

## 10. 备份与还原

### 10.1 进入方式

书库页 → 侧边栏菜单 → **Backup**。

### 10.2 导出备份

- 备份页 → **Export backup** → 选择保存位置（SAF）。
- 输出文件为 zip，结构与桌面版完全一致（包含 `books / notes / bookmarks / plugins / words / config.json`）。
- 桌面端可直接用该备份恢复，反之亦然。

### 10.3 导入备份

- 备份页 → **Import backup** → 选择桌面导出的 zip。
- 应用会：
  1. 解压 zip 到临时目录。
  2. 校验文件结构与 schema。
  3. 写入 Room 数据库（覆盖式 / 合并式视版本而定）。
  4. 还原书籍文件到 `filesDir/books/`。
- 导入完成后，书库自动刷新。

### 10.4 当前边界

- **仅本地备份**：不包含桌面版的云同步功能（OneDrive / WebDAV / S3 等）。
- 安卓 APK 内不携带桌面使用的云同步插件。

## 11. 深链（koodo-reader://）

应用注册了 `koodo-reader://` scheme，可被外部链接唤起：

```
koodo-reader://open?file=...
```

> **当前限制**：深链已被 manifest 声明，但实际路由处理仍在接入过程中。当前版本中点击此类链接会唤起应用，但可能不会直接打开目标书籍。

---

## 12. 多语言

- 应用内语言跟随系统语言设置。
- 已内建的中文 / 英文 语言包：完整 1400+ key。
- 其他 39 种语言（阿拉伯语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语 / …）按需加载：首次切换时会从桌面源代码同步。

切换语言：在系统设置 → 应用 → Koodo Reader → 语言，或直接在系统语言列表切换。

---

## 13. 隐私

- **不申请** 任何存储读取权限；所有本地文件读取均通过 SAF 临时授权。
- **不主动** 上传任何用户数据。
- 阅读统计、笔记、词典、OCR 索引**全部存储在本机**。
- 无任何第三方追踪 SDK。

## 14. 故障排查

### 14.1 启动后白屏 / 卡在加载页

- 检查应用权限是否被禁用（设置 → 应用 → Readme Reader → 权限）。
- 清除应用数据后重启（设置 → 应用 → Readme Reader → 存储 → 清除数据）。

### 14.2 "Open with Readme Reader" 失败

- 部分文件管理器在 Android 11+ 范围存储下仅暴露 `file://` URI，无法被其他应用读取。请改用：
  - 在文件管理器中 **分享 → 发送到 Readme Reader**（使用 `content://`，含系统读取授权）。
  - 或在 Readme Reader 内的导入菜单中选择 SAF。

### 14.3 听书无声音

- 检查系统 TTS 引擎是否已安装：设置 → 系统 → 语言和输入法 → 文字转语音 (TTS)。
- 切换为 Google TTS 或其他可用引擎。
- 在系统的 TTS 设置中测试朗读，确认引擎正常。

### 14.4 OCR 提示 "OCR model unavailable"

- 设备需要 Google Play 服务。
- 设备需要联网以下载首次脚本模型。
- 离线/无 GMS 设备暂不支持 OCR。

### 14.5 词典查询无结果

- 确认所选文本非空白/标点。
- 检查词典管理页是否已启用至少一本词典。
- 检查默认词典是否为对应语言（中文书籍需要中文词典）。

### 14.6 PDF 搜索无结果

- 当前文档为扫描版（无文本层）→ 改用 OCR 入口。
- 加密 PDF 需先解锁再搜索。

### 14.7 备份还原失败

- 确认 zip 文件未被其他进程占用。
- 确认 zip 文件结构与桌面版本匹配；可在桌面端先做一次导出验证。
