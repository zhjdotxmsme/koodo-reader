# ADR-003 兜底岛（WebView 岛）生命周期

- 日期：2026-09-23
- 状态：已采纳（Phase 0）
- 关联：迁移方案 §3.1 格式路由、§6 阶段计划、§7 构建；风险 R6/R7

## 背景

方案 A 的前提收益是：现有 WebView 资产**零作废**，整体降级为兜底岛，迁移期间始终有可发布版本。但双轨并存有确定成本——维护人力分散（R6）、APK 体积膨胀（R7）。若无明确的退出纪律，"临时兜底"会退化为永久双轨。

## 决策

兜底岛生命周期定义为**四态**，逐格式推进而非整体切换：

| 态 | 进入条件 | 行为约定 |
|---|---|---|
| ① 服务期 | 当前 | 全部格式由兜底岛渲染；功能缺陷照常修 |
| ② 收缩期 | P2 起，每完成一个原生格式 | 按 §3.1 路由表把该格式切到 `engine/*`：EPUB(P2) → PDF(P3) → MOBI/AZW3(P4) → TXT/MD/漫画(P5)；切换即跑该格式回归集 + 兜底岛冒烟 |
| ③ 冻结期 | 首个格式切出后 | 兜底岛**只修崩溃，不加功能**；FB2/DOCX/MHTML/HTML 长期驻留兜底岛，直至单独立项（§3.1） |
| ④ 退役 | P8 | 主变体不再加载 WebView；兜底岛代码按 FB2/DOCX 原生进度决定转**动态特性模块**或彻底移除 |

配套纪律：

1. **契约守卫**：`nativeBridge.js` / `folderBridge.js` 协议与其 Jest 测试、构建守卫 `androidBuild.test.js` 在退役完成前**不得删除**——它们是兜底岛与原生壳之间的兼容层。
2. **构建双目标**：`--target webview|native`（已落地，commit `97503d1f`）保证任一时刻都能出纯 WebView 包；`webview` target 永久保留。
3. **体积控制**：双引擎并存期用 ABI 拆分 + 动态特性模块缓解（R7）；P8 移除兜底岛后重测 APK 基线。

## 备选方案与理由

| 备选 | 否决理由 |
|---|---|
| 一次性整体切换、无兜底 | 引擎移植失败风险无缓冲，不可接受（R1） |
| 永久双轨 | R6/R7 成本永久化，违背迁移初衷 |
| 用第三方阅读器 SDK 当兜底 | 数据格式（CFI/schema）与桌面不兼容，破坏 ADR-002 |

## 影响

**正面**：迁移全程可发布；单格式风险隔离；格式路由表使进度可度量（路由表每行即一个里程碑）。
**负面**：冻结纪律依赖执行（对策：本 ADR + PR 审查拒绝兜底岛新功能）；路由切换期同一本书两端排版不同，需 changelog 明示。

## 验证方式

- 每次格式切换：该格式回归集通过 + 兜底岛冒烟通过 + 路由表更新同 PR 提交。
- P8 验收：主变体启动路径无 WebView 加载（systrace/启动日志断言）。

## 回滚方案

格式路由是数据驱动的单表：任一格式回退一行即恢复兜底岛渲染；被移除的兜底岛代码在 git 历史中可完整恢复。
