# Android 规划收尾设计

- 日期：2026-11-25
- 范围：`docs/android-uiux-upgrade-2026-11-19.md`、`docs/superpowers/plans/2026-11-22-android-p0-p1-remainder.md` 的剩余项，以及 2026-11-24 审查发现的选区回归。
- 方案：兼容性完整收尾。保留现有底部弹层、Room 数据格式和双阅读轨，不引入第三方依赖。

## 1. 目标与边界

完成以下可自动验证的工作：

1. 修复底部弹层阻断 Foliate 选区拖动把手的问题。
2. 修复原生文本轨将任意后续选区误判为已高亮的问题，同时兼容旧点 CFI 与新 range CFI。
3. 将中文默认字距降为 0，并让原生轨安全支持设置页已有的负字距。
4. 原生分页按文本脚本选择 CJK `1/1`、拉丁及其他文本 `2/2` 的孤行控制。
5. 将 WebView 列宽量化移入 Foliate 分页几何，覆盖单页和双页，不再跳过 spread。
6. 回写文档，区分自动验证通过与仍需真机验收的项目。

当前环境没有可用 `adb` 设备。触感强度、真机像素列宽、PDF 真机行为和性能基线不标记完成，也不构造模拟结果替代设备数据。

## 2. 选区交互

### 2.1 状态与 UI

`NativeEpubScreen` 增加独立的选区调整状态。Foliate 底部弹层提供“调整选区”入口，原生文本轨不显示该入口。

进入调整模式后：

- 底部弹层暂时隐藏，但 WebView 选区、`selectionCfi` 和 `selectionExcerpt` 保留。
- 两个选区把手显示在根内容层，可以接收拖动。
- 根内容层显示非模态“完成”按钮；点击后重新打开操作弹层。
- 调整模式下返回键只结束调整并重新打开弹层，不退出阅读器。
- 正常关闭操作弹层仍清除选区；离开调整模式本身不得清除选区。

选区 UI 的显示/隐藏决策抽为纯函数，Compose 只负责接线。

### 2.2 拖动边界

`engine.mjs` 的 `extendSelection` 在移动端越过固定端时钳制到相邻位置，不再构造会塌陷的 DOM Range。空选区、跨节点、跨行和触及另一端均返回明确结果，现有 `selectionchange` 回流继续更新把手位置。

## 3. 原生高亮与 CFI 兼容

### 3.1 写入格式

`ChapterLoaderProgress` 提供选区起点和终点 CFI 的构造能力：

- 新高亮和带选区的新笔记保存 range CFI。
- 书签继续保存点 CFI。
- 已有点 CFI 不做数据库迁移。

### 3.2 匹配与删除

原生选区匹配采用精确语义：

- 新数据：当前 range 与已存 range 完全一致才算同一高亮。
- 旧数据：旧点 CFI 与当前选区起点一致才算同一高亮。
- 仅位于旧高亮之后、处于其他章节或与已有高亮部分重叠，都不能据此显示“删除”。

菜单复用同一份匹配结果执行删除，避免“显示已高亮但删除按另一套规则找不到目标”。部分重叠仍允许用户创建独立高亮，不做可能误删用户数据的推断。

### 3.3 点 CFI 消费方

原生跳转、笔记定位和高亮绘制仍需要点 CFI 时，显式通过 `CfiAnchor.startPoint` 取 range 起点。Foliate 轨继续直接消费 range，不改其引擎契约。

## 4. 字距与孤行控制

### 4.1 默认及负字距

`CjkTypography.LETTER_SPACING_SP` 改为 `0f`。原生布局不再要求字距非负，而要求：

- 字距为有限数；
- `fontSizePx + letterSpacingPx > 0`；
- 量化后的字格推进量必须为正，否则放弃量化并保留安全布局。

设置页既有 `-0.1sp..0.1sp` 范围原样传到原生测量、绘制和列宽量化。测试更新为默认 0，并覆盖负字距的测量、绘制参数和退化输入。

### 4.2 按脚本控制孤行

在布局引擎内抽纯函数，按块文本确定最小孤行行数：

- CJK 字符数量大于或等于拉丁字母数量时使用 `1`；
- 拉丁字母占主导，或两者都不存在时使用 `2`。

分页器在每个文本块开始时解析一次该值，替代全局固定 `options.widowsOrphans` 的消费方式。现有引擎默认配置仍保留给外部调用方，Android CJK 阅读轨无需新增持久化字段。

## 5. Foliate 单双页量化

量化职责移入 `paginator.js` 的水平列几何函数。输入增加正文字号与字距，函数基于实际 `columnCount` 计算每列内容宽度，并按完整字格调整：

- 每列左右 side padding；
- 双页中心 column gap；
- 浏览器列宽 hint；
- 对外暴露的 available width。

单页与双页使用同一纯函数。调整发生在分页器内部，不再通过缩小宿主 WebView 间接改变列数，因此删除 `NativeEpubScreen` 的外层 `cjkSidePad` 补偿。

`setViewSettings` 将正文字号和实际字距传给分页器。缺省、非有限值、过窄列和双页均须返回有限、非负几何值；无法安全量化时保留原始布局。

`ReaderCjkColumn` 保留给原生轨及既有 JVM 测试，不再承担 WebView 宿主 padding 反解。

## 6. 错误处理与兼容性

- 不删除或重写旧高亮；坏 CFI 继续按现有降级路径处理。
- 不新增 Room 字段或首选项 key。
- 新用户可见文案走现有 `t()` 与桌面/Android locale 同步流程。
- 所有新增几何、匹配和状态决策均由纯函数承载，Android 框架与 WebView 仅做适配。
- 不修改本轮之外的阅读器导航、主题或数据同步行为。
