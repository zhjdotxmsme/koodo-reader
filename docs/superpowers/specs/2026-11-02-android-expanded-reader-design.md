# Android 阅读器扩展需求设计

> 日期：2026-11-02
> 状态：设计已确认，待书面复核
> 前置规格：`2026-11-02-android-native-consolidation-design.md`
> 范围：领域模型、TXT 规则、书架与阅读 UI、标注管理、搜索、统计、同步快照和响应式布局

## 1. 与前置规格的关系

本规格补充并扩展原生收口，不改变以下已确认决策：

- 唯一发布入口是原生 Compose 壳，正文最终不使用 WebView。
- 常见可重排 EPUB、原生 PDFium、原生漫画和 CBR 明确不支持的边界不变。
- 不迁移、不删除旧 WebView 数据，已有原生数据必须保留。
- 元数据编辑不修改原始 SAF 文件；移动文件只作用于应用私有副本。
- 旧链路只能在新主链路通过验收后删除。

冲突项以本规格为准：TXT 无标题分章改为 5000 字符；同步快照新增统计数据和 S3/MinIO 适配边界；新增完整 UI、标注管理和统计要求。

## 2. 领域模型与持久化映射

用户给出的 `Book`、`Chapter`、`Highlight`、`Note`、`Bookmark`、`ReadingProgress`、`SearchIndex`、`ReadingSession`、`DailyStats` 是统一领域模型，不是要求建立同名物理表。

### 2.1 身份与现有 Room

- 现有 `bookKey: String` 是唯一持久化身份，不额外生成不可映射的 Long 主键。
- `BookEntity`、`NoteEntity`、`BookmarkEntity` 和桌面 schema 保持不变。
- `Book` 领域视图包含书名、作者、路径、格式、封面、大小、删除状态、创建/更新时间和阅读位置；mapper 负责与现有实体互转。
- `Chapter` 使用 `bookKey + chapterId` 身份，包含标题、href、原始起止偏移、资源路径和可用页数。
- `Highlight`/`Note` 复用 `notes` 表：笔记与高亮可以共用一条记录，独立笔记没有高亮矩形；`range` 保存扩展坐标/偏移 JSON，`cfi` 保持桌面兼容。
- `Bookmark` 复用 `bookmarks` 表。
- `ReadingProgress` 使用版本化私有存储，包含章节、偏移、页码、滚动像素位置和最后阅读时间。
- `SearchIndex` 使用按书籍 MD5 隔离的私有索引文件，不进入桌面 Room。
- `ReadingSession` 复用现有 `koodo-stats.db`；`DailyStats` 由会话和标注时间聚合，不保存重复派生数据。

### 2.2 统一解析与渲染接口

- `BookParser`：解析元数据、目录、章节结构和资源路径。
- `ChapterLoader`：按章节或分段加载内容。
- `TextExtractor`：产生用于搜索、复制和笔记关联的纯文本及原始位置映射。
- `PageRenderer`：以同一布局结果支持分页与滚动。
- `AnnotationMapper`：在文本位置、PDF 页面坐标和现有存储模型之间转换。

所有接口与 Android View、Room 和具体同步服务解耦，UI 通过 ViewModel + StateFlow 使用它们。

## 3. 格式细节

### 3.1 EPUB

- 解析 `container.xml`、OPF、NCX/NAV，按 Spine 生成目录。
- 支持 XHTML/HTML 的段落、标题、图片和超链接，章节跳转支持 `href + fragment`。
- 常用 CSS 包含字体、字号、行距、段距、颜色和资源尺寸；按需加载图片与字体。
- 标注绑定 `chapterHref + startOffset/endOffset`，并保留兼容 CFI。
- 只参考其他实现的设计，不复制其代码；固定版式和复杂脚本仍按前置规格拒绝或降级。

### 3.2 PDF

- 主链路使用通过 ABI/16 KB 验收的 PDFium；系统 `PdfRenderer` 只用于辅助快照。
- 支持按需页渲染、缩放、双击放大和页码跳转。
- 文本选择保存 `page + rect + selectedText`；高亮与笔记使用归一化页面区域，不伪造纯文本偏移。
- 大文件不一次性加载全部页面。

### 3.3 MOBI/AZW/AZW3

- 优先复用并完善仓库现有开源 `engine:mobi`，统一输出 title/content/images 章节模型。
- 标注绑定 `chapterIndex + startOffset/endOffset`。
- DRM 明确不支持；可提取正文但结构不完整时允许纯文本降级，并明确提示样式已降级。

### 3.4 TXT/MD

- 自动识别 UTF-8、GBK/GB2312、Big5、Shift_JIS、EUC-KR 等已注册编码。
- 使用按行/字节的有界读取，不整本加载。
- 标题规则优先；无标题时按 5000 个原始字符分章。
- 支持用户自定义标题正则和手动目录锚点；锚点存私有偏好并关联原始字节/字符位置。
- 单章超过 200 KB 时采用分块预加载，不为翻页一次解码整章。
- 标注可映射到 `chapterIndex + lineOffset + charOffset`，持久化同时保留统一章节/字符位置。

## 4. 书架与阅读 UI

### 4.1 书架

- LazyColumn/LazyVerticalGrid 卡片或列表展示封面、书名、作者、格式、进度百分比和最近阅读时间。
- 支持书名、作者、格式、文件大小、最近阅读排序，以及未读状态。
- 长按进入多选/编辑，支持删除、重命名和移动私有书籍副本。
- 优先内嵌封面，失败时使用格式默认占位；加载使用 Compose 骨架或 Shimmer。
- 空状态提供“暂无书籍”和导入按钮。

### 4.2 阅读页

- 默认沉浸式，中央点击切换顶部工具栏和底部进度区。
- 顶部包含返回、目录、搜索和设置；底部显示当前章/总章数、当前页/可用总页数、百分比和剩余阅读时间估算。
- 总页数后台增量计算；未完成时显示“计算中”，不得伪造总数或为首屏整书分页。
- 分页使用 Pager/自定义 Layout，滚动使用 LazyColumn/自定义文本容器，两者共享布局与命中模型。
- 字号、字体、行距、段距、边距、浅色/深灰夜间/护眼/自定义背景、亮度、屏幕常亮和横竖屏设置实时生效并持久化。
- 阅读位置在退出、旋转和进程恢复后恢复。

### 4.3 响应式布局

- 手机单栏；大屏书库多列。
- 大屏阅读支持双页和目录/标注侧边栏。
- PC 仅保留 Compose 响应式边界，不新增 PC 应用或 Kotlin Multiplatform 模块。

## 5. 选择、标注、目录和搜索

- 长按进入选择，拖动起点/终点手柄；弹出复制、高亮、笔记、搜索操作。
- 高亮至少四种颜色；已有高亮可改色、删除并查看关联笔记。
- 笔记可独立或关联高亮，保存原文、内容、创建/修改时间；支持编辑、删除和回跳。
- 书签保存章节、偏移、页码、标题和时间，支持列表、增删和跳转。
- 本书笔记/高亮页支持筛选、编辑、删除、回跳及 JSON/Markdown 导出。
- 目录支持树形展示、当前章高亮和名称筛选。
- 搜索显示章节名、命中片段、命中位置和次数；点击跳转到准确位置。
- 大文本先按章/块建立索引，搜索支持 Loading/Success/Error、取消和重试，不阻塞主线程。
- JSON/Markdown 至少包含书名、章节、原文、笔记内容和时间，并携带可回跳的位置数据。

## 6. 阅读统计

### 6.1 指标

- 今日、本周、本月、累计阅读时长。
- 最近 7 天/30 天趋势和全部时间范围。
- 每本书累计时长、最后阅读时间和 Top 10 排行。
- 按小时的阅读时段分布。
- 按 EPUB/PDF/TXT/MOBI 等格式的时长分布。
- 按书籍和时间的笔记、高亮新增数量。

### 6.2 记录与展示

- 进入阅读页开始计时，退出或进入后台停止；回到前台创建新会话。
- 每 30 秒持久化一次，进程终止最多损失当前未落盘区间。
- 复用现有跨午夜拆分、idle 处理和幂等写入；不得同时维护第二套计时器。
- 统计页使用卡片、折线/柱状图、格式环形图和排行，全部离线可用。
- 统计快照纳入版本化同步数据。

## 7. 同步预留

定义统一 `SyncTarget`/`SyncCoordinator` 和版本化 `SyncSnapshot`，包含：

- 书籍元数据；
- 阅读进度；
- 高亮、笔记和书签；
- 阅读统计；
- 阅读设置。

接口可适配 WebDAV、本地文件夹、S3/MinIO，但本次不实现实际客户端、账号、后台任务、冲突合并 UI 或自动上传。快照 mapper 负责与桌面/后续 PC 端共用数据格式，阅读引擎不依赖网络类型。

## 8. 错误与加载状态

- 书架、导入、解析、搜索、统计和导出分别暴露 Loading/Success/Error。
- 大文件解析展示可取消进度；错误用 Snackbar/页面内重试，不阻塞整个主界面。
- 不用空白正文、虚假页数或静默回退冒充成功。
- 所有异步任务随 ViewModel/页面生命周期取消，图片按显示尺寸解码。

## 9. 验收

- JVM 覆盖领域 mapper、TXT 分块/编码/5000 字分章、位置转换、统计聚合、导出和同步快照 round-trip。
- Compose/Android 测试覆盖多选、编辑、排序、设置持久化、分页/滚动、选择手柄、标注 CRUD、目录/搜索、后台暂停和 30 秒落盘。
- 真实样本覆盖各支持格式及大文件；损坏、DRM、CBR 和无文本 PDF 有明确结果。
- 响应式测试覆盖手机和大屏；深色主题使用深灰与低对比度文字，不要求纯黑。
- 性能门槛沿用前置规格，并新增单章 >200 KB、1000 本导入和长时间阅读计时回归。
- 没有真实设备结果时，不宣称全面收口完成。
