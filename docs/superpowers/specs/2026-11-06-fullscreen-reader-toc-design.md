# 全屏阅读目录设计

## 背景

EPUB 与 PDF 当前分别通过 `ModalBottomSheet` 展示目录。目录只占正文的一部分，并以单条滚动列表呈现。目标是把两种阅读器的目录统一为全屏页面，点击条目后直接回到正文并跳到对应位置。

## 范围

- EPUB 与 PDF 阅读页内的目录改为全屏显示。
- 保留现有章节数据和跳转能力。
- EPUB 保留目录层级缩进；PDF 保留条目页码与加载状态。
- 不新增页码滑块、连续翻页预览、目录搜索或独立导航路由。

## 方案

采用阅读页内切换，而不是新增 NavHost 路由。现有 `showToc`（EPUB）和 `showOutline`（PDF）继续作为界面状态；状态为真时，用全屏目录覆盖阅读内容，不再创建 `ModalBottomSheet`。

提取一个轻量共享全屏目录容器，负责：

- 全屏背景与 `Scaffold` 布局。
- 顶部标题和返回按钮。
- 占满剩余高度的列表内容区域。

EPUB 与 PDF 保留各自的数据项渲染，避免为了统一 UI 而改造 Foliate 目录、原生章节和 PDF outline 的数据模型。

## 交互与数据流

1. 用户点击阅读工具栏的目录按钮，进入全屏目录。
2. 点击顶部返回按钮或系统返回键，仅关闭目录，恢复原阅读位置。
3. 点击 EPUB 条目后，继续调用现有 Foliate `goTo` 或原生章节页跳转逻辑。
4. 点击 PDF 条目后，继续调用 `PdfReaderController.openOutlineRow`。
5. 跳转发起后关闭目录并显示正文；不重建书籍或 Activity。

长目录仍使用 `LazyColumn` 按需组合条目，但这是全屏列表，不再受底部弹窗高度限制。

## 异常与边界

- PDF 目录加载中继续显示现有加载状态。
- 空目录显示空列表，不阻塞返回。
- 沿用现有跳转错误处理，避免跳转失败导致阅读页崩溃。
- 目录打开时系统返回键只能关闭目录，不能退出整本书。

## 验证

- 应用 JVM 单元测试与 nativeHost Debug 构建通过。
- 真机分别打开 EPUB、PDF 目录，确认目录全屏且顶部无重复留白。
- 验证顶部返回和系统返回均恢复原阅读位置。
- 验证点击 EPUB 章节和 PDF outline 条目后落到对应正文位置。
- 验证长目录可以滚动到底部，最后一个条目不被导航栏遮挡。
